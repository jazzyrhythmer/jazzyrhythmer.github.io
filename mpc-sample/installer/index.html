Install 0.3.0.

Use the full SD ZIP for this update. The new engines and kits need their matching plug-ins and catalogue. An app-only update does not install them.

  1. Save your project, power off and back up the entire card, including its existing launcher, projects, samples and user sounds.
  2. Check the stock firmware version. This package supports 1.3.0.12, 1.4.0.7 and 1.4.0.8.
  3. Download and extract RHYTHMER-OS-0.3.0-SD.zip. Compare its SHA-256 with the checksum file.
  4. On 1.3.0.12: copy the supplied autorun/ and Rhythmer/ folders to the card root.
  5. On 1.4.0.7 / 1.4.0.8: first enable Developer Mode in stock firmware under SHIFT + Pad 8 (MIDI CONFIG) → Dev Enhancements (Beta). For a direct installation, copy the supplied root autorun.sh, autorun/ and Rhythmer/ to the card.
  6. If a destination folder already exists, merge its matching contents and subfolders. Update supplied files while preserving your own projects, recordings, samples and User Sounds. Keep all supplied Rhythmer/Plugins/ files together.
  7. Safely eject, insert the card and power on. On firmware 1.4, accept the stock autorun prompt. Confirm 0.3.0 after startup before opening a copy of your existing project.

Already using a boot manager?

Keep its existing root launcher. Do not overwrite a boot manager’s autorun.sh with the standalone script. A direct-SD ZIP and a boot-manager app ZIP have different layouts. Follow the manager’s current firmware-specific instructions and use a matching app package. Keep a backup of the working card before changing the official firmware.

Firmware 1.4 and USB

On stock firmware 1.4, audio runs at 44.1 kHz. USB-camera Screen Mirror is unavailable on 1.4; USB audio and the USB web interface are separate functions. See the manual for the current controls and system pages.

Keep a way back.

Power off and boot without the Rhythmer card to return to stock. Keep manual project saves and recovery files separate; SAVE AS creates an independent copy. No break recordings are bundled—load your own loop.

This is an early beta. Software checks have passed; the public release does not claim physical-device validation for every feature or firmware combination.
